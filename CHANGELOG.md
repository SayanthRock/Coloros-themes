# Changelog

## Next Update

### Improvements

- Updated customer support flow to use public GitHub Releases instead of temporary workflow artifacts.
- Added clearer issue report fields for device, firmware, module version, screenshots, and affected theme area.
- Added roadmap items for wallpapers, icons, lock screen assets, previews, and device compatibility testing.
- Added safer wording around compatibility so customers understand that every firmware must be tested.
- Added release trust improvements through SHA256 checksums, SBOM files, and build provenance.

### Fix Focus

- Theme not applying on some firmware versions
- Missing or incomplete wallpaper assets
- Missing or incomplete icon assets
- Missing or incomplete lock screen assets
- Device-specific compatibility confusion
- Customer installation and rollback guidance

### Safety Rule

New updates should improve measurable issues and compatibility. Do not claim every OPPO, OnePlus, or realme device is fixed until tested device-by-device.
