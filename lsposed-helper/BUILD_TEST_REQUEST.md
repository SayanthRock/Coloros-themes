# Build Test Request

This file records a request to run the APK build workflow after repository changes.

## Requested checks

- Build debug APK.
- Upload debug APK artifact.
- Build release APK output when available.
- Collect release files.
- Verify APK permissions after build.
- Test APK on an OPPO, realme, or OnePlus device.

## Manual device test checklist

- Install APK.
- Open app.
- Check permission screen.
- Test wallpaper picker.
- Test home and lock wallpaper apply.
- Copy support report.
- Share support report.
- Check Feedback, AfterSale, Safe Mode, and status labels when wired into the APK UI.
