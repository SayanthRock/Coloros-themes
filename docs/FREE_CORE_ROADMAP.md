# Free Core Roadmap

ColorOS Themes Rock keeps the normal customer tools free.

## Free core

- Wallpaper picker
- Wallpaper preview
- Home and lock wallpaper apply
- Device report
- Support report copy and share
- Settings shortcuts
- Battery guidance
- Rollback guidance
- Dark mode
- Light mode
- System mode
- Accent color presets

## Optional paid support

Paid support can be offered for setup help, testing help, and custom theme work. It must not lock the normal free tools.

## Feature status labels

Use clear labels in the APK:

- Working
- Safe shortcut
- Preview only
- Needs testing
- Not available

## UI improvement target

The next app change should connect `AppAppearanceManager` to `MainActivity` so the app can repaint itself in dark, light, and system mode.
