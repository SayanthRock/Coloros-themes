# LSPosed Customer Mode

LSPosed support is experimental for this project.

The original LSPosed project is archived and its public README lists support up to Android 14. This repo targets Android 15, Android 16, and Android 17, so each customer device must be tested carefully.

## Safe customer features

- Show device brand, model, Android version, and build info
- Open public Android settings pages
- Help customers collect a support report
- Show theme install guidance
- Keep LSPosed hooks disabled until tested

## Not included

- No banking app modification
- No paid theme conversion
- No private customer data collection
- No hidden background tracking
- No fake performance boost claims

## Recommended customer flow

1. Install root manager and LSPosed-compatible framework if the customer already understands root risk.
2. Install the helper APK.
3. Enable the module only for allowed test scopes.
4. Reboot.
5. Collect report and screenshots.
6. Mark support only for tested device model and firmware.

## Android 15/16/17 rule

Do not advertise this as universal. Android versions, OEM skins, and security patches can change behavior.
