# APK UI Update v0.5.1

This update moves the helper APK to the new free-first premium dark glass UI model.

## Main changes

- New dark dashboard.
- Free Mode card.
- Desert Sand accent color.
- Rounded feature cards.
- New bottom navigation: Home, Theme, Tools, Support, More.
- Clear feature status badges.
- Theme Setup screen for wallpaper and theme actions.
- Tools screen for display and device shortcuts.
- Support screen for report copy and share.
- Settings screen for free mode and UI style toggles.
- MainActivity is now the only launcher screen.

## Build target

```text
Helper APK versionName: 0.5.1
Helper APK versionCode: 10
Module version: v0.5.1
```

## Test checklist

- Build debug APK.
- Open app.
- Check bottom navigation.
- Select wallpaper image.
- Apply wallpaper where supported.
- Copy support report.
- Share support report.
- Check Settings toggles.
- Confirm only one launcher icon appears.
