# APK UI Update v0.5.2

This update converts the helper APK into a sliding liquid-glass style app.

## Main changes

- Transparent liquid glass card effect.
- Sliding page navigation.
- Swipe left and right between pages.
- Bottom slider with arrows and page shortcuts.
- Fast startup dashboard.
- Theme Layers page.
- Performance page.
- Support page.
- More page.
- All layer customization model.
- Troll or demo-only options removed from the customer flow.

## Pages

```text
Home
Theme Layers
Performance
Support
More
```

## Layer model

```text
Base Layer
Wallpaper Layer
Icon Layer
Lock Layer
Status Layer
Support Layer
```

## Performance rule

The app uses lightweight transparent cards and subtle borders instead of heavy live blur. This keeps startup fast and makes the UI smoother on more devices.

## Test checklist

- Build debug APK.
- Open app from launcher.
- Swipe between pages.
- Use bottom slider arrows.
- Select wallpaper image.
- Apply wallpaper where supported.
- Copy support report.
- Share support report.
- Check More page toggles.
- Confirm startup feels fast.
