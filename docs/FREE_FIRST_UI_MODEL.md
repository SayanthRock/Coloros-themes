# Free First UI Model

ColorOS Themes Rock should feel premium, but the normal customer tools should stay free and easy to use.

## Main rule

Use a free-first model:

- Show a clear Free Mode card.
- Do not use forced payment screens.
- Do not use fake premium locks.
- Do not use confusing trial labels.
- Keep optional support messages separate from core tools.
- Show honest feature status for every option.

## Free Mode card

Recommended text:

```text
Free Mode Enabled
ColorOS Themes Rock keeps customer tools open and easy to use. Some options may depend on your phone model, Android version, or required user permission.
```

Recommended actions:

```text
View options
Check device support
Create support report
Open backup and restore
```

## Dashboard model

```text
Dashboard
  Free Mode
  Theme Setup
  Wallpaper
  Performance
  Safety
  Device Status
```

## Feature card model

Each feature card should show:

- Feature name
- Short explanation
- Status badge
- Main action
- Help or report button

## Status labels

| Label | Meaning |
|---|---|
| Safe | Can be used normally |
| Needs test | Device or software version must be checked |
| Needs permission | Extra user approval is required |
| Experimental | May behave differently by device |
| Not supported | Not available on this device |

## Optional support

Optional donation or support messaging can be added later, but it should not block normal customer tools.
