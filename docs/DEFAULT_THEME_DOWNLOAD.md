# Default Theme Download Guide

Use this guide for customers who ask how to download or use the default theme.

## Customer steps

1. Open the latest GitHub Actions build.
2. Download the module ZIP artifact.
3. Install the ZIP using the supported module manager.
4. Reboot the phone.
5. Open the theme folder or wallpaper settings depending on the feature being tested.
6. Send a device report if the theme does not appear.

## Default theme path inside this repo

```text
themes/default/
```

## Module target folder

```text
/system_ext/media/themeInner/
```

## Important note

Not every OPPO, OnePlus, or realme firmware accepts the same theme method. Mark support only after testing the exact phone model and ROM version.
