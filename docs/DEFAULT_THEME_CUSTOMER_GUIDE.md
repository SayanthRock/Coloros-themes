# Default Theme Customer Guide

Use this guide when sharing the default theme with customers.

## Customer steps

1. Download the latest module ZIP.
2. Install it using the supported root manager if the module version is required.
3. Reboot the phone.
4. Apply wallpaper from normal wallpaper settings.
5. Test home screen and lock screen separately.
6. Send a device report if something does not work.

## Default theme options

| Option | Customer action | Status |
|---|---|---|
| Home wallpaper | Apply from wallpaper settings | Safe |
| Lock wallpaper | Apply from wallpaper settings | Safe where supported |
| Theme folder | Install module ZIP | Test required |
| Icons | Use launcher or OEM theme support | Test required |
| Sounds | Apply manually if supported | Test required |
| Support report | Send device and screenshot details | Safe |
