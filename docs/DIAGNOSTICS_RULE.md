# Diagnostics Rule

The app should show clear device and module diagnostics for customers.

## Show in the app

- Root status
- LSPosed status
- Scope status
- Feature status
- Free customer tools

## Status labels

- Working
- Limited
- Needs testing
- Not available

## Rule

Keep free customer tools open. Show advanced or untested items with clear labels so customers know what works, what needs testing, and what is not available on their device.
