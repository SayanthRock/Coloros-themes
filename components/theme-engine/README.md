# Theme Engine

The Theme Engine component handles owned visual assets and customer-safe theme guidance.

## Purpose

- Wallpapers
- Theme previews
- Icon layer notes
- Lock layer notes
- Visual layer status labels

## Default state

Enabled.

## Safety rule

Use only assets that are created, owned, or allowed to be shared. Do not replace protected system app files.

## Customer labels

- Safe
- Ready
- Needs test
- Not supported
